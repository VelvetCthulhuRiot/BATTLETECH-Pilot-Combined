把你的头像 PNG 放在这个目录（可以放到子目录里），mod 会自动扫描，不需要在 JSON 里逐个登记。

★ 目录名必须用下面这几个（否则那批图会被当成"未标注"，启动日志会明确报警）★

    portraits\
        female\     ← 女像（也认 f / woman / women / girl / 女 / 女性）
        male\       ← 男像（也认 m / man / men / boy / 男 / 男性）
        other\      ← 第三类：非二元性别 / 无性别 / 机器人
                      （也认 nonbinary / non-binary / nb / enby / neutral / robot / mech
                         / 无性别 / 非二元 / 其他 / 中性 / 机器人）
        *.png       ← 直接放根目录 = 未标注性别，任何驾驶员都可能分到（一般不推荐）

    注意：`女性头像` / `男性头像` 这种名字**不认**（会把整批图当成未标注）。
    改名成 `female` / `male` / `other` 即可。

另一种等效写法是文件名前缀：`f_01.png` / `m_01.png` / `other_01.png`。

===============================================================================
★ 本融合 mod 特有的一条规则：肖像池优先
===============================================================================

「**头像池决定有哪些性别可用**，性别比例只在这个可用空间内分配。」（见 移交文档 第 6 节）

  · 只生成**有替换头像**的那些性别。例如 `other\` 是空的，就一个非二元性别驾驶员都不会生成。
  · 男女比例会在这个可用范围内**重新归一**：配置里 女80% / 男10% / 其他10%，
    若 `other\` 为空，实际就是 女 88.9% / 男 11.1%（8:1 的比值不变）。
  · 一张图都没有 ⇒ 头像替换整体不可开启（此时本 mod 只剩性别比例调节功能）。
  · 想知道**当前实际生效的权重**，看日志里的这一行：
        [PilotCombined] 性别刷出比例已生效（最终权重）：女 … / 男 … / …
    带 `★ 已按『肖像池优先』裁剪` 就说明这条规则真的在起作用。

===============================================================================
驾驶员性别是怎么定的
===============================================================================

游戏里的驾驶员性别是游戏自己定的（3D 驾驶员按脸型 headMesh 推：>0.6 女、<=0.4 男、
中间为第三类；固定头像驾驶员读 JSON 里的 Gender）。mod 只在"同性别"的图里挑，
所以**你不需要逐张手工关联**，扔进对应目录就行，几百张也能直接用。

===============================================================================
图片要求（建议，不是硬性）
===============================================================================

  - 格式：PNG（也支持 JPG / DDS，PNG 兼容性最好）
  - 尺寸：**正方形**，512x512 最合适；1024x1024 也行
    · 非正方形会被拉伸，请先裁成正方形
    · 不要用 2048x2048 以上：每张图会被缩放缓存成 4 档（64/128/256/512），大图很吃显存
  - 透明背景 or 不透明背景**都可以**，mod 原样透传，不做任何抠图或合成：
    · 透明背景 → 露出游戏面板底色，最接近原版观感
    · 不透明背景（RGB 无 alpha）→ 整张图作为一个方形"卡面"显示
  - 不需要手动对齐人脸，UI 按中心显示

===============================================================================
改完怎么生效、怎么排查
===============================================================================

  · 图片池只在启动时扫一次 ⇒ 加完图**重启游戏**，或者按 **F9** 打开设置窗口点
    「立即重扫图片池」（**不用重启**，推荐）。
  · 同一个驾驶员每次都是同一张图（按哈希分配），日志里能看到分配过程：
        分配 -> pilotDefId=… | pool/hash/female[40] | portraits/female/20.png
  · 日志文件只有一个：`mods\PilotCombined\PilotCombined.log`
    （启动时会被清空重写，所以要看就趁游戏没关）。
  · 设置都在 `mods\PilotCombined\combined.json`：
      portraits.enabled              关掉就完全不换头像
      portraits.autoScan             默认 true = 自动扫本目录
      portraits.pool                 显式图片池（留空 = 用 autoScan）
      portraits.poolMode             hash（推荐）| sequential
      portraits.rules                给特定驾驶员固定某张图的规则
