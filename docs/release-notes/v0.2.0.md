# PilotCombined v0.2.0

把「驾驶员性别刷出比例」和「驾驶员头像替换」合成一个 MOD，并加上把两者绑在一起的那条规则：

> **肖像池决定"有哪些性别可用"，性别比例只在这个可用空间内分配。**

没有非二元头像，就不会生成非二元驾驶员；比例会在"你真的有图"的性别之间重新归一。
界面会**如实**说明这件事 —— 所有不可能生效的控件都会变灰，并写明原因。

---

## 安装

1. 下载本页附件 `PilotCombined-0.2.0.zip`，解压得到 `PilotCombined\` 文件夹。
2. 把它整个拷进：

   ```
   %USERPROFILE%\Documents\My Games\BattleTech\mods\
   ```

   最终应当是 `mods\PilotCombined\PilotCombined.dll` + `mod.json` + `combined.json` + `loc\` + `portraits\`。
3. 启动游戏，在游戏内 **MODS（模组）** 界面确认它已启用。
4. 任意界面按 **F9** 打开设置面板。

> 需要正版 BATTLETECH 1.9.1-686R，用游戏自带的 MOD 加载器即可，**不需要 ModTek**。
> MOD 不修改任何游戏原文件、不写入存档，删掉文件夹即完全恢复。

## 关于图片

**附件里的 `portraits\` 是空的**（发布包里不放头像素材）。启用头像替换需要你自己的正方形图片：

```
mods\PilotCombined\portraits\
    female\   女
    male\     男
    other\    非二元 / 无性别 / 仿生人
```

* 本仓库的 `mod\portraits\` 目录下带着一套示例素材（本地 ComfyUI 生成、本地脚本抠图，
  512×512 PNG），可以直接拷进去用；出处与许可说明见仓库 `docs\素材与许可.md`。
* 想换成自己的图：方形 PNG，512×512 最合适；透明底或不透明底都行，MOD 原样透传。
* 加完图**不用重启**：按 **F9** → 「立即重扫图片池」。

## 这个版本有什么

* **单 DLL / 单配置 / 单日志**：两个旧 MOD 合并完成（旧的 `GenderRatio` + `PortraitSwap`）。
* **肖像池优先**：只生成有头像的性别，比例在可用范围内重新归一；
  一张图都没有时头像替换自动关闭（此时只剩比例调节）。
* **角色创建头像列表重建**：格子数 = 图片数，一张图一格，不重复、不遗漏；
  选「他们」= 全部图片。
* **F9 面板**：运行中开关头像替换（**不用重启**）、立即重扫图片池、如实灰化、
  状态行显示真正生效的权重。
* **界面多语言**：跟随游戏语言（中文 / English）；加语言只需往 `loc\` 放一个 JSON 文件，
  不用重新编译。德文、俄文的槽位已留好。
* 离线测试 130 项断言 + 部署校验工具（`tools\`）。

## 已知限制

* 单个性别池超过 **90 张**时，超出部分不会出现在角色创建列表里（游戏那个列表只有 90 格），
  但仍会用于随机生成的驾驶员。
* 德文 / 俄文暂无翻译（会回退英文）。
* `combined.json` 的注释与日志文案目前只有中文。
* 退出游戏时原版会打一条 `MessageCenter [ERROR] CRITICAL ERROR` —— 原版行为，与本 MOD 无关。

## 反馈

有问题请开 issue，附上 `mods\PilotCombined\PilotCombined.log`（每次启动会重写）会更方便定位。
